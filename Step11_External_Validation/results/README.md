Expected content (manuscript): 17/18 directionally concordant, 18/18 BH-FDR
< 0.05, all four hub genes lower in lesional skin (paired *p* < 0.001) with
AUC 0.876 / 0.771 / 0.943 / 0.744 (APOE / PLIN1 / BCL2 / ADIPOQ).

**Method (11 November 2026).** The published statistics use the
ArrayExpress `E-GEOD-30999` processed values and the **MaxMean** probe rule
(one representative probe per gene, selected by highest mean expression across
all 170 samples), identical to the discovery-cohort preprocessing. The
selected probe for each of the 18 genes is listed in the supplementary table
and in `../scripts/input/representative_probes.csv`. Earlier DeLong confidence
intervals that were on the opposite ROC direction from their AUCs were
corrected on 9 November 2026; all intervals in the current table are on the
same direction as their AUCs.
