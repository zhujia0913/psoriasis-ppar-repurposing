< 0.05, all four hub genes lower in lesional skin (paired *p* < 0.001) with
AUC 0.864 / 0.771 / 0.750 / 0.744 (APOE / PLIN1 / BCL2 / ADIPOQ).

**Correction (9 November 2026).** Nine DeLong confidence intervals in the
original table were written on the opposite ROC direction from the AUC in the
same row (for example FABP5: AUC 0.9845 with "0.000-0.032"). They have been
replaced by `1 - upper` / `1 - lower` (for example "0.968-1.000"), so that
every reported AUC now lies inside its own 95% CI. The four hub-gene CIs
(APOE 0.808-0.921, PLIN1 0.698-0.844, BCL2 0.672-0.827, ADIPOQ 0.667-0.821)
were already correct and are unchanged, as are all AUCs, *p* values, FDRs,
medians and direction calls. The three copies of this table (repository,
local working package and submission supplementary file) are byte-identical
(md5 `89d120708946827c1d028f8d3beb2c3c`).
