# Step 11 — External validation in an independent psoriasis cohort (GSE30999)

Analysis code and numerical results for the external-validation stage of the
psoriasis PPAR drug-repurposing study. **Journal-independent**: this directory
contains only code and the underlying numerical results; no target journal is
assumed, and supplementary-file names/numbering are maintained separately in
the submission package.

The validation cohort **GSE30999** (NCBI GEO; Affymetrix HG-U133 Plus 2.0 /
GPL570) shares no samples with the three discovery cohorts (GSE13355,
GSE14905, GSE78097) used in Steps 1–9.

## 1. What is validated

| Object | Definition | Derived in |
|--------|------------|------------|
| **18 PPAR-targeted DEGs** | 759 psoriasis DEGs ∩ 177 experimentally verified PPAR targets | Step 2 |
| **4 hub genes** | ADIPOQ, APOE, PLIN1, BCL2 (PPI network, CytoHubba rank sum) | Steps 4–5 |

Both sets are pre-specified inputs in `scripts/input/`; they are **not**
re-derived in this step.

## 2. Validation cohort and data source

- 85 patients with moderate-to-severe psoriasis; 170 paired lesional /
  non-lesional skin biopsies (85 L + 85 NL).
- **81 complete pairs** retained for the paired analysis.
- Input files are the **ArrayExpress / BioStudies** processed files for
  `E-GEOD-30999` (the ArrayExpress mirror of GSE30999), obtainable from
  `https://ftp.ebi.ac.uk/pub/databases/arrayexpress/data/experiment/GEOD/E-GEOD-30999/`:
  - `E-GEOD-30999.processed.1.zip` — 170 per-sample `ID_REF / VALUE` tables,
    54,675 probes, RMA-normalized log2 values rounded to two decimals
    (39,798,039 bytes)
  - `E-GEOD-30999.sdrf.txt` — sample/phenotype table (109,410 bytes;
    md5 `55d99d97c869f534a6f29ea6df85437e`)

  These two files are **not committed** to this repository. `00_fetch_data.R`
  downloads them when missing; set `GSE30999_DATA_DIR` to read them from an
  existing local directory. See `data/README.md`.

## 3. Methods

1. Probes are mapped to gene symbols with the **same annotation table used for
   the discovery cohorts** (`../Step1_DEG/probe2gene_AnnoProbe.tsv`, 41,937
   probe→gene mappings). For genes represented by multiple probes, a single
   **representative probe is selected by the MaxMean rule** — the probe with the
   highest mean expression across all 170 samples. This is identical to
   `collapse_probes()` in `Step1_DEG/deg_standard_pipeline_v2_AnnoProbe.R` and
   is the rule stated in manuscript Methods 2.2.11. The 18 selected probes are
   shipped in `scripts/input/representative_probes.csv` and in the
   supplementary table.
2. **Paired** Wilcoxon signed-rank test (lesional vs autologous non-lesional);
   Benjamini–Hochberg FDR applied **within the pre-specified 18-gene set**.
3. ROC / AUC with **95% CI by the DeLong method**; positive class =
   non-lesional, ROC direction resolved automatically (`direction = "auto"`),
   with CI endpoints flipped together with the AUC when AUC < 0.5.
4. Direction concordance of the log2 fold change vs the discovery cohort.

Reported results: **17/18** directionally concordant, **18/18** BH-FDR < 0.05,
all four hub genes significantly lower in lesional skin (paired *p* < 0.001);
AUC 0.876 (APOE), 0.771 (PLIN1), 0.943 (BCL2), 0.744 (ADIPOQ).

## 5. How to run

Requirements: **R ≥ 4.3**, CRAN `pROC`, `ggplot2`, `gridExtra`, `ragg`.
No Bioconductor packages are needed for this step.

```bash
cd Step11_External_Validation
Rscript scripts/00_fetch_data.R          # E-GEOD-30999 -> verify local files
Rscript scripts/01_preprocess.R          # MaxMean collapse + 81 pairs -> data/*.rds
Rscript scripts/02_external_validation.R # table -> results/, figure -> figures/
```

If the processed files are already available elsewhere:

```bash
GSE30999_DATA_DIR=/path/to/data Rscript scripts/00_fetch_data.R
GSE30999_DATA_DIR=/path/to/data Rscript scripts/01_preprocess.R
Rscript scripts/02_external_validation.R
```

`02_external_validation.R` writes a 600-dpi PNG (5908 × 5413 px) and a PDF;
`figures/README.md` gives the one-line conversion to the journal-ready LZW
TIFF archived in `results/`. A fixed random seed (`set.seed(20261111)`) makes
the jittered points reproducible pixel-for-pixel.

## 7. Reproducibility status

Verified on 11 November 2026 with R 4.5.0 (`pROC`, `ggplot2`, `gridExtra`,
`ragg`). All three scripts ran end to end without error:

| Check | Result |
|-------|--------|
| `00_fetch_data.R` | both files present; byte sizes and SDRF md5 match the official ArrayExpress files |
| `01_preprocess.R` | 170 samples, 85 L + 85 NL, 89 individuals, **81 complete pairs**; 54,675 probes → 20,188 genes; 18/18 signature genes present |
| `02_external_validation.R` | **18/18** BH-FDR < 0.05, **17/18** directionally concordant |
| Table | `results/external_validation_table.csv` matches every cell of the supplementary `.xlsx` (18 × 11) |
| Figure | `results/Fig16_external_validation.tif` is the LZW TIFF of the 600-dpi PNG produced by script 02 |
| Independent check | Python 3 / numpy + scipy re-implementation (probe selection, medians, paired Wilcoxon, rank-based AUC, BH-FDR) agrees on **18/18** rows; see `results/reproducibility_check.tsv` and `results/external_validation_table_regenerated.csv` |

The reported numbers are therefore fully reproducible from the archived code
and the public source files. There is no longer a discrepancy between the
reported table and a regenerated table.
