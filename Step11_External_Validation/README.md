# Step 11 — External validation in an independent psoriasis cohort (GSE30999)

Analysis code and numerical results for the external-validation stage of the
psoriasis PPAR drug-repurposing study. **Journal-independent**: this directory
contains only code and the underlying numerical results; no target journal is
assumed, and supplementary-file names/numbering are maintained separately in
the submission package.

The validation cohort **GSE30999** (NCBI GEO; Affymetrix HG-U133 Plus 2.0 /
GPL570) shares no samples with the three discovery cohorts (GSE13355,
GSE14905, GSE78097) used in Steps 1–9.

## 1. What is validated

| Object | Definition | Derived in |
|--------|------------|------------|
| **18 PPAR-targeted DEGs** | 759 psoriasis DEGs ∩ 177 experimentally verified PPAR targets | Step 2 |
| **4 hub genes** | ADIPOQ, APOE, PLIN1, BCL2 (PPI network, CytoHubba rank sum) | Steps 4–5 |

Both sets are pre-specified inputs in `scripts/input/`; they are **not**
re-derived in this step.

## 2. Validation cohort

- 85 patients with moderate-to-severe psoriasis; 170 paired lesional /
  non-lesional skin biopsies.
- **81 complete pairs** retained after quality control for the paired analysis.

## 3. Methods

1. RMA-normalized (log2) processed values; probes mapped to gene symbols and
   multiple probes per gene collapsed to the **median**.
2. **Paired** Wilcoxon signed-rank test (lesional vs autologous non-lesional);
   Benjamini–Hochberg FDR applied **within the pre-specified 18-gene set**.
3. ROC / AUC with **95% CI by the DeLong method**; positive class =
   non-lesional, ROC direction resolved automatically (`direction = "auto"`).
4. Direction concordance of the log2 fold change vs the discovery cohort.

Reported results: **17/18** directionally concordant, **18/18** BH-FDR < 0.05,
all four hub genes significantly lower in lesional skin (paired *p* < 0.001);
AUC 0.864 (APOE), 0.771 (PLIN1), 0.750 (BCL2), 0.744 (ADIPOQ).

## 5. How to run

Requirements: **R ≥ 4.3**, Bioconductor `GEOquery` and `hgu133plus2.db`,
CRAN `pROC`, `ggplot2`, `reshape2`, `gridExtra`.

```bash
cd Step11_External_Validation
Rscript scripts/00_fetch_data.R          # GSE30999 -> data/*.rds (needs internet)
Rscript scripts/01_preprocess.R          # annotate + pair -> data/*.rds
Rscript scripts/02_external_validation.R # table -> results/, figure -> figures/
```

`00_fetch_data.R` reuses a local `data/GSE30999_series_matrix.txt.gz` when
present, otherwise downloads it from GEO (~12 MB; not redistributed).
`01_preprocess.R` prints the metadata columns and warns if the number of
complete pairs differs from 81 — verify the lesion-status and patient-ID
parsing against the downloaded metadata before relying on the pairing.

## 7. Reproducibility status

Verified on 9 November 2026 with R 4.5.0, GEOquery 2.80.0,
`hgu133plus2.db`, `pROC`, `ggplot2`, against the public GSE30999 series
matrix (12 MB; 54,675 probes x 170 samples). All three scripts ran end to end
without error:

| Check | Result |
|-------|--------|
| `00_fetch_data.R` / `01_preprocess.R` / `02_external_validation.R` | all exit 0 |
| Lesion labels / patient IDs | cross-checked against `biopsy type:ch1` and `subject:ch1` |
| Complete lesional / non-lesional pairs | **81** (85 NL + 85 LS), matching the manuscript |
| Gene-level matrix | 21,355 symbols x 170 samples |
| Pre-specified signature | 18/18 genes present |
| Runtime outputs | `results/external_validation_table_regenerated.csv`, `figures/Fig16_external_validation.pdf` / `.png` |

**The regenerated numbers are not identical to the reported supplementary
table, and the two files are not interchangeable.** `01_preprocess.R` collapses
all probes mapping to a gene with the **median**, as stated in the manuscript
Methods. The reported table was generated with a different probe-selection
rule (one representative probe per gene; e.g. APOE = `203382_s_at`, LDLR =
`202067_s_at`, RBP4 = `219140_s_at`). Under median collapsing, 12/18
median-expression pairs and 14/18 AUCs (within 0.01) reproduce; the
exceptions are APOE, BCL2, HBEGF, LDLR, NAMPT and RBP4. BCL2 is the largest
discrepancy (reported AUC 0.750 / *p* = 8.05e-08; regenerated AUC 0.522 /
*p* = 0.155), and the signature-level summaries change from 18/18 BH-FDR
< 0.05 and 17/18 directionally concordant to 17/18 and 16/18 respectively.

`results/reproducibility_check.tsv` gives the full reported-vs-regenerated
comparison. `results/external_validation_table.xlsx` remains the reference
copy of the reported supplementary table;
`results/external_validation_table_regenerated.csv` is the independent
recomputation provided for transparency. Cite the reference table, not the
regenerated CSV, when referring to the published statistics.

Nine DeLong confidence intervals in the reference table were corrected on
9 November 2026 (flipped to the same ROC direction as their AUCs); the four
hub-gene CIs were already correct. See `results/README.md`. No other cell of
the reference table was changed.
